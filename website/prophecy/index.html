Cómo leer este mapa

No todas las afirmaciones tienen el mismo nivel.

Este recurso distingue entre texto explícito de la Escritura, armonización, interpretación, cronología del proyecto y asuntos no resueltos. Las etiquetas muestran el nivel de cada afirmación.

La Escritura es la autoridad máxima. Las armonizaciones y cronologías identificadas aquí pertenecen al marco interpretativo de La Última Vigilia y no se presentan como texto bíblico explícito.
